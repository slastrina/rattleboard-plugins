# Word scramble

A word with its letters mixed up and a hint (an animal, something to eat, a place or a thing). The answer flips up on the next page. A new word every time it comes round in the rotation (Rattleboard 0.10.7 and later; earlier versions change every hour), and not one it used recently.

Settings:
- Words: all kinds, or just animals, food, places or things.

Notes:
- Nothing is fetched: about 140 words are built in.
- This is a script plugin (Rattleboard 0.8.0 or later) with no network access at all.

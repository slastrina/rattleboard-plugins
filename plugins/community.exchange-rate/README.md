# Exchange rate

Shows the latest reference exchange rate between two currencies, and the date it was published.

Settings:
- From: the currency you're converting from (default USD).
- To: the currency you're converting to (default EUR).

Notes:
- Data: Frankfurter (frankfurter.dev), which publishes the European Central Bank's reference rates. No account or key.
- The ECB publishes new rates once each working day, around 16:00 CET, so this checks hourly.
- Rates are shown to two decimal places. Choose two different currencies.

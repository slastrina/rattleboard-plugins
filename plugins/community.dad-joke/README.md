# Dad joke

A dad joke, a new one every time it comes round in the rotation (Rattleboard 0.10.7 and later; earlier versions get a new one every hour). Long jokes continue on a second or third card. It remembers the last 100 jokes it told, so they don't come round again soon. Click the board to open the joke's page.

Notes:
- Data: [icanhazdadjoke.com](https://icanhazdadjoke.com), free, no account or key. Please keep it to one source of these per board.
- This is a script plugin (Rattleboard 0.8.0 or later). It only contacts icanhazdadjoke.com.

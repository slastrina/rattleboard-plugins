# Next public holiday

Shows the next public holiday, the day it falls on and how many days are left. The corner turns from green to yellow (a month away), orange (a week) and red (tomorrow or today).

Settings:
- Country: where you live.
- State or region (optional): a code like AU-VIC, US-CA or DE-BY, to include that region's own holidays (Melbourne Cup, say). Leave it empty for national holidays only.

Notes:
- Data: [Nager.Date](https://date.nager.at), a free public-holiday API. No account or key.
- Checks every 6 hours.
- This is a script plugin (Rattleboard 0.8.0 or later). It only contacts date.nager.at.

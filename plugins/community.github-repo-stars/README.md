# GitHub stars

Shows how many stars a public GitHub repository has.

Settings:
- Owner: the user or organisation, like slastrina.
- Repository: the repository's name, like rattleboard.

Notes:
- Data: the GitHub REST API (api.github.com). No account or key.
- Checks hourly. GitHub allows 60 requests an hour per network without a key, shared by everything on your network, so keep to a few of these sources.
- Private repositories aren't supported.

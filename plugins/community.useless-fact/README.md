# Useless fact

A weird fact, new every time it comes round in the rotation (Rattleboard 0.10.7 and later; earlier versions get a new one every hour). It remembers the last 100 it showed, so they don't come round again soon. Long ones continue on a second page.

They're for fun: the collection is a classic list of "useless facts", and not every one of them is true.

Notes:
- Data: [uselessfacts.jsph.pl](https://uselessfacts.jsph.pl), free, no account or key.
- Clicking the board opens the fact's source, when it has a secure (https) one.
- This is a script plugin (Rattleboard 0.8.0 or later). It only contacts uselessfacts.jsph.pl.

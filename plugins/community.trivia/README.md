# Trivia

A trivia question, then its answer on the next page a little later. Every time it comes round in the rotation it's a new question (Rattleboard 0.10.7 and later; earlier versions get a new one every hour). True-or-false questions say so.

Settings:
- Category: anything, or one of ten, like Science and nature, History or Film.
- Difficulty: any, easy, medium or hard.

Notes:
- Data: the [Open Trivia Database](https://opentdb.com), free, no account or key (CC BY-SA 4.0). It takes 20 questions at a time and keeps them, so it asks the site once every 20 questions; the site allows one request every 5 seconds.
- Only questions that fit your board (in up to two pages) and use characters the board has are shown.
- This is a script plugin (Rattleboard 0.8.0 or later). It only contacts opentdb.com.

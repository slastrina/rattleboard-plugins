# Bitcoin price

Shows the current price of bitcoin in the currency you choose, and how much it has changed in the last 24 hours (in percent).

Settings:
- Currency: US dollar (default), euro, British pound, Australian, Canadian or New Zealand dollar, yen, Swiss franc or Indian rupee.

Notes:
- Data: CoinGecko's free public API (api.coingecko.com). No account or key. Price data by CoinGecko.
- Checks every 15 minutes, well within CoinGecko's public rate limits.
- For information only; not financial advice.

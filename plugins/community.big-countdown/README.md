# Big countdown

The number of days to go, drawn big in colour tiles, with what it counts to beside it and a bar along the bottom that fills, red to violet, as the day gets closer. On the day itself it interrupts once with a rainbow "is today!" card. Small boards (Compact) show it as text.

Settings:
- What it counts to: a short name, like Christmas or Launch day.
- Date: the day.
- Bar starts on (optional): where the bar starts filling. Leave it empty and it starts on the day you add the source.
- Colour: rainbow digits and bar, or one colour.

Notes:
- Nothing is fetched: the card is drawn on your device, and redrawn as the days go by.
- This is a script plugin (Rattleboard 0.8.0 or later) with no network access at all. It shows how a script can draw a whole board, tile by tile, with "characters".
